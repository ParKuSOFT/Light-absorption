# 👩‍💻 Задание для разработчика UI/ViewModel (Ветка `feature/ui`)

**Проект:** Light-absorption (Виртуальный физический эксперимент)
**Зона ответственности:** Визуализация, привязка данных (Data Binding), команды и взаимодействие с пользователем (паттерн MVVM). 
**Правило:** Не пишем физику и математику, только вызываем методы из `Light-absorption.Core`.

> ⚠️ **Важно:** Делайте коммиты после каждого шага. В конце запушьте ветку и откройте Pull Request в `main`.

---

### 🛠 Шаг 1. Подготовка окружения и создание проекта
1. Сделайте `git pull origin main` (чтобы подтянуть созданный Solution).
2. Переключитесь на ветку `feature/ui`.
3. Создайте проект **WPF Application** (рекомендуется для чистого MVVM) или WinForms (если требуют строго его, но тогда придется использовать паттерн MVP). Назовите его **`Light-absorption.UI`**.
4. Установите NuGet-пакет **`CommunityToolkit.Mvvm`** (он сильно упростит создание ViewModel и команд).
5. Установите NuGet-пакет для графиков, например, **`OxyPlot.Wpf`** или **`LiveCharts`**.

---

### 🧠 Шаг 2. Создание ViewModel (изоляция от физики)
*На этом этапе Человек 1 может еще не закончить Core, поэтому используйте временные заглушки (mock-данные) для проверки интерфейса.*

1. Создайте класс `MainViewModel` (наследуйтесь от `ObservableObject` из CommunityToolkit).
2. Создайте свойства для привязки (Binding):
   * `double MaxDepth` — максимальная глубина \(z\) (например, по умолчанию 2 метра).
   * Коллекции для графика: `ZValues`, `RValues`, `GValues`, `BValues` (или используйте `PlotModel` из OxyPlot).
   * Коллекция `List<ExperimentState>` (или `ObservableCollection`) для хранения истории вычислений.
3. Создайте команды (`RelayCommand`):
   * `CalculateCommand` — вызывает `BeerLambertModel` (или `EulerSolver`) и заполняет массивы для графика.
   * `ExportCommand` — вызывает `CsvExporter` (через интерфейс, чтобы не было жесткой связи).

---

### 🎨 Шаг 3. Разработка интерфейса (View)
1. Сверстайте главное окно `MainWindow.xaml`:
   * Поле ввода (TextBox) или Слайдер (Slider) для ввода максимальной глубины \(z\).
   * Кнопка **«Рассчитать»**.
   * Кнопка **«Экспорт в CSV»**.
   * Место под график (элемент управления от выбранной библиотеки).
   * Визуализация текущих значений R, G, B (например, три цветных прямоугольника, яркость которых меняется в зависимости от глубины).
2. Привяжите `DataContext` окна к `MainViewModel`.

---

### 🔗 Шаг 4. Интеграция с Core (после готовности ядра)
1. Сделайте `git merge main` (или подтяните ветку `feature/core`, если она еще не слита, чтобы получить доступ к классам).
2. Замените заглушки в `MainViewModel` на реальные вызовы классов из `Light-absorption.Core`.
3. Настройте график так, чтобы по оси X откладывалась глубина \(z\), а по оси Y — интенсивность. Сделайте три линии: красную, зеленую и синюю (согласно цветам каналов).
4. Проверьте, что нажатие кнопок корректно вызывает математику и сохраняет файл.

---

### 🚀 Финализация
1. Убедитесь, что приложение запускается и корректно строит графики.
2. Сделайте `git push origin feature/ui`.
3. Откройте Pull Request в ветку `main`.
